# 附录图（Extended Data）审查与重绘

审查方式：两个 agent 并行审计 12 张附录图的**变量计算**与**绘制**，我对其中影响结论的每一条
独立复核后才采信。下面标 **【已复核】** 的是我自己跑数验证过的。

结论先说：**附录问题比正文严重得多。** 有三类错误会直接误导读者——
凭空捏造的数据、把不可行/罚金主导的 run 当成有效结果画出来、以及一张**符号画反了的**敏感性图。

## 一、最严重的三个（都已复核）

### 1. 敏感性龙卷风图有两根柱子符号是反的 —— 因为它在比较两个不同的模型

**【已复核】** `BASE` 有 **18** 个成本科目，含 `air_retrofit_capex`；**每一个 `SA_*` run 只有 17 个**，
没有这一项。原因是 BASE 在本轮重解（2026-08-19），而整个 SA 族是 2026-08-09 的构建产物——
那时**干冷改造这个机制还不存在**。

于是 ED Fig 3 的龙卷风图不是在做敏感性分析，而是在**差分两个不同的模型**，偏移大到能翻转结论：

| | 图上画的 | 用同构建的 BASE 重锚后 |
|---|---|---|
| `SA_ammonia_cost_50` | **+0.548%** | **−0.109%** |
| 管道走廊（`SA_pipe_*`） | +0.34 … +0.50% | −0.31 … −0.15% |

**六根柱子里有两根符号是反的。** 而且现有的任何守卫都抓不到它：`plot_extended.py` 里
`assert_same_vintage` 的命中数是 **0**，而 `input_vintage` 只比对**水**的右端项——这次变的不是水。

**已动手**：22 个 SA 情景正在双通道重解（`scripts/resolve_sa_family.sh`，约 3.7 小时）。
在跑完之前，这张图上的任何结论都不成立。

### 2. 一个**不可行**的 run 被画成了图里最好的脱碳路径

**【已复核】** `RQ3_retire_only` 的 `global_objective_cny = nan`，
`status = infeasible_or_unbounded`，而它的逐年残余排放是 `{2030: 0.0, 2040: 0.0, 2050: 0.0, 2060: 0.0}`。
ED Fig 2 无条件 `ax.plot` 它（`:533`），于是它在图上是一条**贴着零的水平线**——
视觉上是全图最优的路径。代码在 `:523` 其实检测到了 `unsolved`，但只用来改线型。

同一张图上，`RQ3_ccs_only`（2030 年目标函数的 **93.5%** 是 big-M 罚金，总目标是 BASE 的 **19.9 倍**）
把 y 轴下沿压到 −1220 Mt，把六条真实轨迹全挤扁了。

### 3. 三张地图给**没有煤电的省份**编造数值，其中两处填在色标的极端

**【已复核】** 34 个省级多边形里只有 **28 个**有机组。没有机组的 6 个是
**北京、香港、澳门、上海、台湾、西藏**。三处填充：

| 位置 | 代码 | 填了什么 | 后果 |
|---|---|---|---|
| ED4 面板 (b) | `:818` `fillna(1.0)` | **100% 退役** | 色标顶端；西藏成了图上最大的一块深色 |
| ED4 面板 (a) | `:809` `fillna(0)` | 0% CCS | 色标底端；**同一批省份在 (a) 读作 0%、在 (b) 读作 100%** |
