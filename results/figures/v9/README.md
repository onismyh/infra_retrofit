## 三、相对冻结旧图变了什么

### 3.1 输入：海上汇从 25 个封存体变成 11 个盆地级汇

旧 v9 的 103 个汇里海上有 25 个，多数是同一沉积盆地里被拆开的小封存体，比文献常用的
"渤海湾 / 南黄海 / 东海 / 珠江口 / 北部湾 / 琼东南 / 莺歌海"七盆地口径细得多；陆上的口径与
文献相差不大。合并只动海上、只按盆地、注入能力不变，所以：

* 汇数 103 → **89**（−14，全部来自海上 DSA 与 EOR 的盆地内合并）；
* 候选边 2 677 → **2 651**（少的是海上小封存体之间的三角边）；
* 总封存量 1 902.5 Gt 不变，可建设注入能力 1 350 Mt yr⁻¹ 不变；
* 求解规模：681 690 变量、302 262 约束、1 653 572 非零元（wd085）。

## 四、哪些结论不许从这批图里读

### 4.1 没有种子族，容量级结论一律不能判"可分辨"

本批只有三个情景，**没有任何一对仅换种子的复现**。CLAUDE.md §二 4 要求的简并度地板
`1.96·√2·range/d2(k)` 因此**算不出来**。后果：

* 可以写的只有两类：**目标函数的可证区间**（§一的三行，那是 Gurobi 的界，不需要地板）
  和**空冷改造量**（旧 v9 实测 24.5 倍越过地板，且这次 +221 GW 的差值比旧的 +209 GW 更大——
  但严格说这次的地板还没测）。
* 捕集量、CCS / BECCS / 生物质容量、退役量、在用汇个数、海上注入占比的三情景差值
  **一律只能描述，不能下"水约束改变了 X"或"没有改变 X"的判定**。
  ED14 台账里"匹配到 / 未匹配"的两口径差别同理。
* ED2、ED5、ED8、ED9 画的都是 BASE 与 s = 0.85 的点对点差值，它们是**描述性的**，
  在种子族补上之前不要从中读显著性。

### 4.2 只有一个水文臂

所有"考虑水"的结论都来自 CWatM × GFDL-ESM4 × SSP1-2.6 一条臂。旧 v9 的 WaterGAP 臂区间跨零
（附录 A §4.2）说明**单臂结论对水文模型敏感**，SSP3-7.0 与 WaterGAP 臂补上之前，
"水约束效应为正"只能写成"在 CWatM SSP1-2.6 下为正"。

### 4.3 s = 0 那一档仍然不是"水不重要"

区间 [−0.42, +1.24]% 跨零是因为存量取水权全给电力时约束不咬，与旧 v9 §3.3 的解释相同。

### 4.4 ED14 是 2050 年横截面

上排三张地图与 d 台账都是 2050 年；2030 年捕集为 0、2060 年退役过半，横截面选 2050
是因为三条链同时活跃。不能把 2050 年的匹配比例说成"规划期内"的比例，逐年曲线在 e–g。

### 4.5 不要跨版本相减

v7（35 汇 / 923 边）、v8（103 汇 / 1.5 pp）、冻结旧 v9（103 汇 / 2.0 pp / 混合容差）、
本批（89 汇 / 2.0 pp / 全 1%）是四套模型。`frozen_103sink_lost_tree/` 里的任何数字
都不能与 `data/` 里的数字相减。

### A.1 全中文

* 字体统一为 **SimHei**（与 `thesis.ipynb` 一致，单字体不配 fallback 栈），
  在 `plot_style.py` **模块级**生效 —— 九个 ED 脚本从不调用 `apply_style()`，
  英文时代无所谓，改中文后会让整张图变成空心方框（实测 ED8 一次 537 条缺字警告）。
* 路径配色换成**同族同色系**表（深端 = 带 CCS，浅端 = 不带 CCS），取代原 Tol bright 系。
* 新增两个必需的基础设施，否则中文图必错：
  * `CJKLogFormatter` —— log 轴的 `$\mathdefault{10^{-2}}$` 中，`\mathdefault` 恒定
    解析到正文字体，而 SimHei 没有 U+2212，且 mathtext 不做逐字回退。
    实测 `mathtext.default`、`font.family` 回退栈、`axes.unicode_minus` **都救不了**。
  * `cjk_fill()` —— `textwrap.fill` 按字符数折行，汉字宽度是拉丁的两倍，
    同样 `width=210` 的图注英文排 181 mm、中文排 **272 mm**，图幅直接从 183 撑到 280 mm。
