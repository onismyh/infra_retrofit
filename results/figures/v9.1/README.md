## 二、和 v9 到底哪里不一样

v9（`_wd085` 族）：

```
节点可用量 = 订正径流 × WATER_EXTRACTABLE_FRACTION(0.20) × (1 − existing_withdrawal_share(0.85))
约束作用在：耗水
```

`optimization/data_prep.py` 自己的注释写着这两个系数是**别名化的**——求解器只看得见乘积
0.03，所以任何靠动 `existing_withdrawal_share` 做的对照，都分不清"生态流量标准在起作用"
还是"分配规则在起作用"。而且分母是当地天然径流，对北方流域根本不成立：海河的实际用水就
超过它自己的径流，靠南水北调和地下水撑着。

v9.1（`_oq` 族）把这一条拆成两条，各自约束它本来就是在讲的那个量：

```
节点   ≤ 订正径流 × 0.20                          生态流量规则，作用在耗水（枯竭规则）
流域   ≤ 用水总量控制指标 − 非电既有取水            分配规则，  作用在取水（公报计量口径）
```

`existing_withdrawal_share` 在 `_oq` 族里不再使用——分配规则改成从国办发〔2013〕2号读，
不再假设。**两者不能同时设**，否则分配规则被算两遍。

### 口径是这次最容易错的地方

| | 直流冷却贯流水量 | 全国煤电（本模型） |
|---|---|---|
| 取水定额（水节约〔2019〕373号） | **不计** | 96.2 亿 m³ |
| 《公报》用水量 ← 指标对它执法 | **计入**（直流火核电 453.8 亿是工业用水子项） | 521.1 亿 m³（标定后） |
| 耗水量 | 不适用 | 60.6 亿 m³ |

指标是对**用水量**执法的，所以流域约束必须作用在**取水**。用定额会低估约 5 倍。

模型原始取水强度是 Macknick(2011) 美国值，算出煤电一家 984 亿 m³/yr，比全国工业用水总量
953.7 还大；按 `basin_bias_factors` 同一乘性做法标定 k=0.495 → 521.1 亿。
自洽性检验：西北诸河标定前后同为 11.2 亿（该流域无直流机组），与公报该栏 0.0 一致。

**副作用（很重要）**：在取水口径下，空冷改造消掉的是整个贯流量约 90 m³/MWh，
而不是耗水口径下的约 1 m³/MWh。所以空冷从"省一点水"变成对指标最有效的合规手段，
`WA_cwatm_126_dry_oq_noair` 就是测这个的。

> 量级相当（§三之三）。合计占用 3.9% 与"约束不起作用"是两回事——流域内部分节点已经贴到

原口径 `_wd085` 的问题不是"太紧"，而是把这两件事乘成了一个没有制度对应物的 0.03 系数，
以至于任何结果都说不清是哪一条在起作用。

一起还装得下吗？** 两者争的是同一套流域指标，而绿氢路线的电解水还要额外耗水。

## 四之四、水在证据链里到底起什么作用

按本轮 20 个情景真实求解与预算侧实测，逐条列出**有证据的**和**没有证据的**，
供撰写正文时取用。**不得把"未分辨"的项写成效应。**

**1. 水改变的是路径与空间，不是减排总量。**
2030 年全国空冷改造 44.4 → 87.2 GW（seed 中位，+42.8，地板 14.40，**3.0×，已分辨**）；
同期捕集量与退役量的变化分别是地板的 **0.21×** 与 **0.04×**，**未分辨**（§三之五）。
可以说"水约束把机队推向空冷"，**不能**说"水约束使捕集量下降 6 Mt"。

**2. 物理响应很大，成本信号几乎为零。**
第一档（仅生态流量）的目标函数差 +0.023%，是 seed 地板的 **0.05×**；第二档 +0.451%，1.04×。
**成本差与物理响应是两个不同的测量**，不得用前者判断后者是否发生——这是本版更正过一次的错误
（§四之二 的 ⚠）。

**3. 水的紧约束是制度性的，不是水文性的。**
西北内陆河的余量之所以只有 2.1 亿，是因为它 2025 年实际用水 729 亿已超过 2030 年分摊指标
641 亿，压缩后才剩这么点；不是因为当地径流少。**分母是配额，不是径流**——这正是 v9.1 换口径
的意义（§二）。

**4. "最紧的流域"与"响应最大的流域"不是同一个。**
按反事实紧度：生态流量档只有海河越 100%；按实际响应：落在黄河（+22.3，21.5× 地板）与
西北内陆河（+20.7，1.5×）。海河一动不动，因为 2030 年排放目标尚不约束、捕集为 0
（§五.7）。**两者不得互换引用。**

**5. 约束咬住的地方，简并度也消失。**
仅生态流量档下西北内陆河在 40 与 50 GW 之间摇摆（占全国 seed 极差的 95%）；加上总量指标后
四个 seed 完全相同（99.11 GW），该流域利用率四年恰好 1.000（§三之三之二）。

**6. 水不是全国性约束。**
九个流域里八个有正余量，全国合计占用远低于 100%。**"水制约中国煤电减排"这种全国性叙述
没有证据**；有证据的是"水在一个流域决定路径选择"。

**7. 唯一咬住的那个流域，结论取决于一个尚未建模的东西。**
西北内陆河被执行的余量 2.1 亿里，有 2.4 亿是加回来的已建模工业取水——**扣回量比余量本身还大**。
即煤电在该流域拿到的空间几乎全部是工业点源当前占用的水。**工业在本版仍是外生的**，
一旦成为决策变量，两者在同一个额度里竞争，该流域的煤电结论会变（§五.5）。
`ed_fig15_source_atlas` 面板 (b) 就是把这一条画出来。

> **一句话**：水在这里不是"能不能减排"的约束，而是"用哪条路径、在哪个流域减排"的约束；
> 它只在一个流域真正咬住，而那个流域的答案又几乎完全取决于工业是否进入决策。

## 五、哪些结论不许从这批图里读

1. **不许把 v9.1 的任何量与 v9 相减。** 口径不同，差值无物理意义。
2. **不许把预算侧的"装得下"读成"约束不起作用"。** 全机队全 CCS 的取水在八个流域装得下
   （最紧的长江 86%），但这**不等于**约束松弛：真实求解里生态流量档与总量指标档各自推动了
   +48.1 与 +42.3 GW 的空冷改造（§三之三）。逐节点约束不能用流域合计判断。
   同样，长江在全 CCS 下已用掉 86% 的余量，而工业点源在同一流域里争同一套指标——
   煤电单独的结论不能外推到煤电 + 工业。
3. **西北诸河超指标这一判断对分摊权重敏感。** 需水权重下压缩前为 −85.5 亿，面积权重下会翻成正。
   必须同时报两个权重的结果，不得只报一个。超指标流域的预留按 `compliance_ratio`
   等比压缩（全用户同比例压减，不是只压电力），压缩后煤电在西北诸河只剩 2.1 亿 m³ 合法空间。
4. **未核实假设：`用水总量` 考核是否把直流冷却水全额计入。** 本版按《公报》的表述假设
   "计入"。**但这条不确定性是单向的**：若实际考核对直流回归水另有处理，机队对指标的占用
   只会更小（长江从 49% 掉到约 3%），约束更松。所以它**动摇不了**§四之二 的结论，
   只会加强它。仍应在方法学里写明按哪一条口径执行，但不再是投稿前的阻断项。
5. **工业部门的水已从预留里扣出（73.9 亿 m³/yr），但工业还没进求解器。**
   在工业成为决策变量之前，这部分余量是空着的，不得解读为"工业有多少水可用"。
   在西北诸河这条尤其要紧：该流域被执行的余量只有 2.1 亿，而加回去的已建模工业取水是
   2.4 亿——**扣回量比余量本身还大**。也就是说，煤电在唯一一个总量指标真正咬住的流域里
   所拿到的那点空间，几乎全部来自尚未进入求解器的工业点源。**该流域的煤电结论不得外推
   到"电力 + 工业"的联合配置。**
6. **`existing_withdrawal_share = 0.85` 的论证链在本版作废**，相关的
   `_wd085` 敏感性轴（wd056/wd070/wd090）在 `_oq` 下不存在。图 2 的面板 b、c 已重做：
   b 改为逐流域两档利用率（对数轴，各按自己的分母），c 改为 BASE→仅生态流量→＋总量指标
   的三级阶梯响应分解，每一步配简并度地板，未越过地板者标"未分辨"。
7. **两档的"最紧流域"不是同一个，也不要与"响应最大的流域"混为一谈。**
   按反事实紧度：生态流量档只有海河越 100%（全捕集 102.7%，现状 55.5%），
   总量指标档只有西北诸河越限（全捕集 1078%，现状已 533%）。
   按实际响应：生态流量档落在黄河与西北内陆河，海河一动不动——因为 2030 年排放目标尚不
   约束、各情景捕集量均为 0，海河那个 102.7% 是模型并不选择的全捕集反事实。
   ED 流域特写按**响应**选流域（黄河 | 西北内陆河），Fig 2(b) 报**紧度**排名，两者不得互换。
8. **配额切片必须点明。** 枯水期配额随 (年份, SSP 成员集) 变：海河在 2060/SSP3-7.0 下是
   16.84 亿 m³，在 2030/全 20 成员下是 15.76。Fig 1(c) 用前者，Fig 2(b) 与 ED 特写用后者，
   `plot_fig1_water_footprint.basin_drying(year, ssp)` 现在强制调用方指定。**跨图引用前先对切片。**
9. **"余量"有两个数，只有一个被执行。** `指标 − 预留`（全国 1510 亿）是口径说明用的
   中间量；约束右端项是 `指标 − 预留×compliance_ratio + 已建模工业×compliance_ratio`
   （全国 1671 亿，写进 `inputs/water_basin_caps.csv` 的 `residual_1e8_m3`）。两者在长江
   差 18 亿（577 vs 595），在西北诸河差一个符号（−85.5 vs +2.1）。
   **引占比时一律用后者**：长江 49%、珠江 42%、海河 29%、全国 31%——不是曾经流传的
   51/44/32/35。`scripts/diagnose_official_water_budget.py` 现在两列并排打印并标注哪列被执行。
10. **厂址→流域有两套归属规则，合计量会差几个百分点。** ED 特写用"最近可达供水节点"
    （`ed_plant_data.plant_basin`），Fig 2/3 用"最近流域多边形"（`plot_style.assign_basin`），
    共同覆盖厂址上一致率 93.5%。黄河第一步：ED 图 20 GW，`hub_frame` 口径 22.6 GW。
    **两处的数不要互相引用。**
11. **不许把 `IND_*` 的运行与本版任何量相减。** 2026-09-08 起仓库里多了一支联合情景
    （`IND_BASE`、`IND_WA_cwatm_126_dry_oq`），它把 390 个工业厂址变成决策主体，接进同一张
    CO₂ 管网、同一个流域取水额度和**同一个排放目标**。那是**另一个模型**：目标函数的分母从
    5 392 Mt 变成 8 661 Mt，源群从 350 个煤电厂址变成 350 + 390。前缀 `IND_` 就是为此设的
    ——本仓库的后缀（`_noair`/`_capfree`/`_seedN`）表示"同一个模型的一个旋钮"，那些才可以相减。
    本版的图与结论全部建立在**工业外生、其现状取水整份让给煤电**之上；见 §四之四.7。
    实现与参数出处：`docs/工业联合减排实现说明.md`。
