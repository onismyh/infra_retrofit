## 二、和 v9 到底哪里不一样

v9（`_wd085` 族）：

```
节点可用量 = 订正径流 × WATER_EXTRACTABLE_FRACTION(0.20) × (1 − existing_withdrawal_share(0.85))
约束作用在：耗水
```

`optimization/data_prep.py` 自己的注释写着这两个系数是**别名化的**——求解器只看得见乘积
0.03，所以任何靠动 `existing_withdrawal_share` 做的对照，都分不清"生态流量标准在起作用"
还是"分配规则在起作用"。而且分母是当地天然径流，对北方流域根本不成立：海河的实际用水就
超过它自己的径流，靠南水北调和地下水撑着。

v9.1（`_oq` 族）把这一条拆成两条，各自约束它本来就是在讲的那个量：

```
节点   ≤ 订正径流 × 0.20                          生态流量规则，作用在耗水（枯竭规则）
流域   ≤ 用水总量控制指标 − 非电既有取水            分配规则，  作用在取水（公报计量口径）
```

`existing_withdrawal_share` 在 `_oq` 族里不再使用——分配规则改成从国办发〔2013〕2号读，
不再假设。**两者不能同时设**，否则分配规则被算两遍。

### 口径是这次最容易错的地方

| | 直流冷却贯流水量 | 全国煤电（本模型） |
|---|---|---|
| 取水定额（水节约〔2019〕373号） | **不计** | 96.2 亿 m³ |
| 《公报》用水量 ← 指标对它执法 | **计入**（直流火核电 453.8 亿是工业用水子项） | 521.1 亿 m³（标定后） |
| 耗水量 | 不适用 | 60.6 亿 m³ |

指标是对**用水量**执法的，所以流域约束必须作用在**取水**。用定额会低估约 5 倍。

模型原始取水强度是 Macknick(2011) 美国值，算出煤电一家 984 亿 m³/yr，比全国工业用水总量
953.7 还大；按 `basin_bias_factors` 同一乘性做法标定 k=0.495 → 521.1 亿。
自洽性检验：西北诸河标定前后同为 11.2 亿（该流域无直流机组），与公报该栏 0.0 一致。

**副作用（很重要）**：在取水口径下，空冷改造消掉的是整个贯流量约 90 m³/MWh，
而不是耗水口径下的约 1 m³/MWh。所以空冷从"省一点水"变成对指标最有效的合规手段，
`WA_cwatm_126_dry_oq_noair` 就是测这个的。

## 五、哪些结论不许从这批图里读

1. **不许把 v9.1 的任何量与 v9 相减。** 口径不同，差值无物理意义。
2. **不许说"水不再是约束"就完了。** 全国余量宽（煤电占 35%）不等于处处宽：
   长江 49%、珠江 42% 是真紧的地方，且长江之紧来自直流冷却而非缺水。
3. **西北诸河超指标这一判断对分摊权重敏感。** 需水权重下压缩前为 −85.5 亿，面积权重下会翻成正。
   必须同时报两个权重的结果，不得只报一个。超指标流域的预留按 `compliance_ratio`
   等比压缩（全用户同比例压减，不是只压电力），压缩后煤电在西北诸河只剩 2.1 亿 m³ 合法空间。
4. **最大的未核实假设：`用水总量` 考核是否把直流冷却水全额计入。** 本版按《公报》
   的表述假设"计入"。若实际考核对直流回归水另有处理，长江会从 49% 掉到约 3%，
   结论方向就变了。**这一条核实之前不得投稿。**
5. **工业部门的水已从预留里扣出（73.9 亿 m³/yr），但工业还没进求解器。**
   在工业成为决策变量之前，这部分余量是空着的，不得解读为"工业有多少水可用"。
6. **`existing_withdrawal_share = 0.85` 的论证链在本版作废**，相关的
   `_wd085` 敏感性轴（wd056/wd070/wd090）在 `_oq` 下不存在，图 2(b) 需要重新设计。
