## 二、现在做了什么

### 2.1 三条通路

每个厂址每个规划年在 `unabated / ccs / h2` 上分配份额，和为 1，连续变量。
`h2` 只在 `SECTOR_HAS_H2_ROUTE` 为真的行业开放——实测确认：

```
cement       n=150  h2 route=关
steel_eaf    n= 40  h2 route=关
steel_bf_bof n= 80  h2 route=开
ammonia      n= 60  h2 route=开
methanol     n= 60  h2 route=开
```

**份额跨年单调不减**（`ccs` 与 `h2` 各自单调）。因为和为 1，这同时禁止了"拆掉捕集装置去建 DRI 竖炉"
这种物理上不会发生的切换。单调性不是装饰：它正是**按平准化成本逐年计费合法的前提**（见 §2.4）。

**没有退役通路。** 工业产量在本模型里是外生的，一个厂址"停产"会让产量凭空消失而不是转移出去。
产量能不能降是需求侧问题，本模型不回答。

### 2.2 三处真正的"联合"

| | 怎么联合的 | 代码位置 |
|---|---|---|
| **CO₂ 管网** | 工业厂址建 `industry::<hub_id>` 节点 + 一条到最近节点的支线，与煤电**同一张图、同一批候选边、同一批 35 个汇、同一组注入上限** | `optimization/network.py` |
| **流域取水上限** | 工业厂址水 + 工业捕集增量水，与煤电取水**记在同一条约束的同一个余量里** | `optimization/solver.py` 流域块 |
| **单一联合总目标** | `煤电减排 + 工业减排 + 缺口 ≥ target × (煤电基线 + 工业基线)` | `optimization/solver.py` 排放目标块 |

管网侧实测：节点 612 → 1002（+390），边 923 → 1313（+390），**390 个厂址全部注册**。

> **注册是硬断言，不是警告。** 源点没进 `industry_node_ids` 时，它的 `captured` 变量不会被任何
> 节点平衡约束绑住，捕集的 CO₂ 会零成本蒸发，而模型会照样报出这份减排量。所以缺一个就抛异常。

> **工业支线的最近节点可能是某个煤电厂址节点或某个封存节点**（因为节点集合是边加边找的）。
> 这不是缺陷：节点平衡写的是"净流出 == 该点自身的捕集量"，过境的工业流量算进"流入"，
> 于是该点必须多送出同样多，质量守恒不破。而共用集输点恰恰就是"共用基础设施"的物理含义。

### 2.3 单一联合总目标改变了什么

```
分母：煤电 5 392.20 Mt + 工业 3 269.25 Mt = 8 661.44 Mt
```

**同一个 target 份额要求的绝对减排量放大 1.61 倍。** 这是"单一联合总目标"的定义本身，不是副作用。

#### 目标水平（作者 2026-09-08 定）

现有的 `emission_target_fraction = (0, 0, 0, 0.95)` 是按**煤电单独基线**定的。直接搬到联合分母上
会把 2060 年的要求从 5 122 Mt 抬到 8 228 Mt——那不是"换了分母"，是**换了目标水平**。

作者选定：**2060 年的绝对减排量保持不变**，联合份额随之改为

```
0.95 × 5 392.1966 / 8 661.4434 = 0.591424  →  0.5914
要求 5 122.38 Mt（煤电单口径 5 122.59 Mt，差 −0.21 Mt）
```

> ⚠ **这个取舍在求解后被推翻，见 §七之二。** 当时反对 0.95 的理由是"煤电最多减 5 392 Mt
> （= 其基线）"，那个上界是错的：BECCS 的 reduction 系数是 1.05，煤电在**经济最优处**就已经
> 到 5 923 Mt。而 0.5914 的实测结果是**排放目标完全不咬**——煤电一家超额 16%，工业没有任何
> 碳上的理由动作，"单一联合总目标"无物可分配。**目标要到份额 > 5 923.4/8 661.4 = 0.684
> 才开始咬住。** 因此 2026-09-09 增设 `_t95` 一对（份额 0.95），保留 0.5914 一对作对照。

**由此产生一条硬纪律**：开工业的运行与不开工业的运行**不得相减**。目标函数、约束、源群三者同时变了。
所以情景用 **`IND_` 前缀**而不是后缀——本仓库的后缀（`_noair`/`_capfree`/`_seedN`）一直表示
"同一个模型的一个旋钮"，那些是可以相减的。

`include_industry` **默认关闭**，因此 2026-09-08 之前求解的全部情景在 (模型, 参数, 线程数) 上不变。

### 2.4 成本口径

工业按**吨**计价并且是**平准化的**（含资本回收），与 Tang et al. (2023, iScience 26:106347) 的
`Z_cap = CAPEX·CRF + OPEX` 一致；煤电那边仍按 MW / MWh、资本在存量增量上一次性计费。
两套口径**互不混用**，只在共享管网、共享流域额度、共同目标三处相遇。

平准化成本逐年计费**只有在决策不可逆时才成立**，这就是 §2.1 单调性的作用。
把它拆回一次性 CAPEX 需要一个 CRF 和一个资本占比，而两份中文来源都没公布这两个数——
`INDUSTRY_CAPTURE_CAPEX_SHARE` 与 `INDUSTRY_H2_CAPEX_SHARE` 因此**只用于 `industry_detail.csv`
的展示拆分，不进模型算术**。

## 三、参数与出处

### 3.1 CO₂ 捕集成本（元/t CO₂ 捕集，**只含捕集**）

运输与封存来自管网与汇，**不在这个数里**——把文献里的"CCUS 全链成本"塞进来会重复计价。

| 行业 | 取值 | 来源与区间 |
|---|---|---|
| 水泥 | **540** | 中国能源新闻网 2023（ACCA21 口径）430–650；ACCA21《中国 CCUS 年度报告(2023)》305–730 |
| 钢铁（高炉-转炉） | **454** | 同上 348–560 |
| 钢铁（电炉） | **540** | ⚠ **假设**：无中文来源给电炉捕集成本。电炉烟气更稀更间歇，比水泥窑更难，故取水泥值。电炉占已建模工业 CO₂ 的 1.7%（56/3 269 Mt），驱动不了任何结论 |
| 合成氨 | **177.5** | ACCA21 高浓度化工 105–250 |
| 甲醇 | **177.5** | 同上（气化合成气变换后同一流股类别） |

排序是物理的：捕集成本随烟气 CO₂ 浓度倒数变化——水泥窑约 14–33%（含煅烧 CO₂）、
高炉煤气 20–27%、煤气化合成气变换后 >95%。

**交叉校验**：五行业产量加权均值约 430 元/t；Tang et al. (2023) 报全链 50.6 $/t，
其中运输 2.1、封存 6.9，即捕集约 41.6 $/t ≈ 291 元/t——更低，因为那是 2050 年（已含学习）
且其中 59% 是更便宜的电力部门。

捕集成本走**与煤电改造同一条学习曲线** `assumptions.ccs_learning_factor(year)`。
给工业单独一条曲线会让行业间的分配变成建模者的任意选择，而不是技术本身的差别。

### 3.2 工业捕集的水耗

**1.65 m³/t CO₂**（Wang, Wen & Xu, *Nat Commun* 16:4251, 2025，区间 1.60–1.69）。
叠加在该行业 GB/T 18916 单位产品取水之上。

实测量级：全部工业上 CCS 时取水 **73.9 → 122.4 亿 m³/yr**，捕集增量 **48.5 亿 m³/yr**。

### 3.3 氢替代路线

**减排上限**（⚠ 三个都是路线化学判断，不是引用值）：

| 行业 | 可减比例 | 残余是什么 |
|---|---|---|
| 钢铁（高炉-转炉） | 0.85 | H₂-DRI + 电炉替掉焦炭还原后，石灰、电极、电炉自身用电仍在（1.8 t CO₂/t 粗钢中的 0.2–0.3） |
| 合成氨 | 0.95 | 绿氢完整替掉气化 + 变换，公用工程与空分仍在 |
| 甲醇 | 0.90 | 绿氢调 H/C 比，并不移除碳原料，残余大于合成氨 |

**成本**：一阶展开，锚点 + 氢价斜率

```
premium(P) = premium_ref + h2_intensity × 1000 × (P − P_ref)      元/t 产品
             （下限 = premium_ref × 资本占比，见下）
```

氢强度**不是常数**，取自点源表自身的 `h2_demand / production`（81 / 180 / 190 kg H₂ 每吨
粗钢 / 氨 / 甲醇），所以斜率是逐厂址的。

| 行业 | premium_ref（元/t 产品） | P_ref（元/kg H₂） | 来源 |
|---|---|---|---|
| 钢铁 | 1 575 | 35.0 | Transition Asia / Global Efficiency Intelligence《Green Steel Economics》2024：中国绿色溢价约 225 USD/t 粗钢 @ 5 USD/kg H₂，按仓库的 7.0 元/USD 折算 |
| 合成氨 | 400 | 12.0 | 中国能源新闻网 2023：绿氢合成氨约 2 870 元/t vs 煤制 2 380–2 560 元/t |
| 甲醇 | 3 000 | 16.5 | 新能源网 2024：绿氢制甲醇 4 500–5 500 元/t @ 绿氢 15–18 元/kg vs 化石约 2 000 元/t |

三个锚点故意停在**各自来源假设的氢价**上，展开式再把它们移到模型的氢价；先平均到统一 P_ref
会丢信息而不是增加信息。

**氢价**取自本仓库自己的 `inputs/ammonia_supply_curve.csv`（`weighted_lcoh_usd_per_kg_h2`，
按供给量加权的全国均值）——**和煤电掺氨用的是同一份数据集**，两处用氢不可能被两条曲线定价：

| 年份 | 2030 | 2040 | 2050 | 2060 |
|---|---|---|---|---|
| 元/kg H₂ | 24.8 | 18.1 | 14.3 | 12.4 |

**下限（必须有）**：路线自身的重建资本（DRI 竖炉 + 电炉；电解槽供料的合成回路）**不随氢价下降**，
所以溢价不可能低于它。没有这个下限，展开式在 2060 年对钢铁给出 **−255 元/t**：
`1575 + 81×(12.4−35) = −255`，模型会被"倒贴"去改造每一座高炉，1 437 Mt 减排凭空免费。
那是把**绿地对绿地**的文献锚点错用到了资本已沉没的存量厂——切换不可能比继续运行一个已付清的资产更便宜。
下限取 `premium_ref × 资本占比`。

**结果（元/t CO₂）**：

| 氢价年 | 钢铁 H₂ | 合成氨 H₂ | 甲醇 H₂ | | 对照 CCS（未含学习） |
|---|---|---|---|---|---|
| 2030 | 489 | 838 | 1 686 | | 钢铁 454 |
| 2040 | 360 | 464 | 1 217 | | 水泥 540 |
| 2050 | 360 | 252 | 951 | | 合成氨/甲醇 177.5 |
| 2060 | 360 | 146 | 818 | | |

排序有意义：**只有钢铁的氢路线与 CCS 正面竞争**（2030 年 489 vs 454，差 8%）；
合成氨要到 2050 年后氢价降下来才越过 CCS；甲醇的气化 CO₂ 太便宜捕，氢路线始终没机会。

### 3.4 氢路线的厂内水

取该行业的**先进值**而非通用值。这不是猜：先进值按定义就是**新建与改建**项目适用的取水定额，
而氢路线就是改建。GB/T 18916 没有 H₂-DRI 行，另一条路是自己编一个。
比值取行业默认原料行（三个行业落在 0.61–0.73），开关 `INDUSTRY_H2_USES_ADVANCED_QUOTA`。

## 四、已知偏差（方向已知，必须写进 Methods）

1. **氢路线成本被低估** → **氢的采纳量是上界**。锚点是绿地对绿地的平准化成本比较，用在存量厂上
   缺了被沉没的高炉资本。旋钮：`scenario.industry_h2_cost_multiplier`。
2. **电解水耗没有计入**（10–22 L/kg H₂，Arup 2022；Energy UK 2022）。它属于**电解槽所在流域**，
   不属于工业厂址。煤电掺氨那边同样没计，所以至少两边一致——但工业全替代需要 103 Mt H₂/yr，
   对应 **10–23 亿 m³/yr，是西北内陆河被执行余量（2.1 亿）的 5–11 倍**。
   将来无论怎么补，都必须补在供给节点上，且两个用氢方**同时**计费。
3. **氢供给既没有容量上限也没有空间匹配。** 工业按全国均价买氢，不从供给节点取，
   所以与煤电掺氨**不争同一份供给**。2030 年该曲线可供 1 555 Mt H₂/yr，而全替代只需 103 Mt/yr，
   全国尺度上这个缺失的上限不咬；**缺的空间匹配才是真缺口，也是扩展的第一件事**。
4. **工业产量外生。** 无退役、无需求响应、无材料效率。厂址只能改变"同样多的吨怎么造出来"。
5. **西北内陆河在结构上放不下。** K 的被执行余量 2.1 亿 m³，而工业现状取水一家就是 2.4 亿，
   煤电另有 11.2 亿。工业在本实现里**没有节水改造通路**（只有氢路线附带的先进值），
   所以 K 会出现无法消除的松弛。**这不是 bug，是这套官方指标口径在西北的算术结论**，
   `slack_detail.csv` 会逐流域报出来。要不要给工业加"节水改造"通路，是作者的取舍。

### 6.1 顺带修掉的 M4

`_biomass_access_matrices` 每个规划年重建一次 13 949 × 71 148 的 float64 稠密零矩阵（7.39 GiB），
四个年份同时被 `year_payloads` 持有 = **30.3 GiB**。这才是 CLAUDE.md §二.5"最多 2 路并发"的真实成因。

改成**末次缓存 + scipy CSR 稀疏**后：**7.58 GiB → 1.76 MB**（四年合计 30.3 GiB → 7 MB）。
已逐元素验证新旧矩阵完全相同（71 148 个非零一一对应），第二次调用命中缓存。
**接工业之前必须先做这个**：再加一个源群会把稠密路径推到 60 GiB。

**可复现性已验证，不是推断**：把同形状的稠密矩阵（含显式零）与其 CSR 等价物分别送进
`addConstr`，Gurobi 的约束矩阵 `getA()` **逐元素相同**（`(A_dense != A_sparse).nnz == 0`），
非零数也相同——`addConstr` 在写入时就把零系数丢掉了（日志里那句
`zero or small (< 1e-13) coefficients, ignored` 说的正是这件事）。
所以 M4 **没有改变 (模型, 参数, 线程数) 三元组**，打补丁后重跑 v9.1 仍然可复现。

> `_v91tree/` 未同步本次工业改动，保持冻结；v9.1 的存档结果仍是基准。

## 七之二、首轮求解结果（0.5914 一对，2026-09-08）

| | 目标函数 | gap | 耗时 |
|---|---|---|---|
| `IND_BASE` | 1.393929e13 | 0.78% | 3 236 s |

两个运行在 2060 年都出现 **286.7–290.1 Mt/yr 的注入能力松弛**。查网络本身：

* ~~注入能力的空间分布是约束~~ → 是 **v7 网络的连通性缺陷**。
* ~~源汇匹配给出了"汇饱和"的结论~~ → 那是**输入版本缺陷**，不是结论。
* ~~工业转氢是因为封存被堵死~~ → 是因为捕集下来的 CO₂ **在这张网上没地方去**。
  65.2–65.7% 的氢份额不可引用。

CLAUDE.md §二.6 记的 "v8 = 重建版本（103 个汇、**连通性修复网络**）" 说的正是这个缺陷，

在其上重跑四个 `IND_*` 情景。拼装为何不算跨版本混用、以及新旧网络的对比，见 `_indtree/README.md`。

### 5. ⚠ 成本差不可直接引用

目标函数差 +1 491.7 十亿元 = **+11.03%**。三条限制，缺一条这个数就会被误用：

**(a) 一半以上是罚参数。** 按类别拆开：

| 类别 | Δ（十亿元） | 是否高于容差 |
|---|---|---|
| **松弛罚金（big-M）** | **+806.7** | 是 |
| 增量运维 | +505.3 | 是 |
| 工业改造 | +245.3 | 是 |
| 基准净成本 | +221.4 | 是 |
| 碳成本 | −135.3 | 勉强（地板 135.2） |
| 水成本 / 生物质 / 搁浅资产 / 其他 | −97 / −57 / +57 / −53 | **否，不可读** |

罚金占 **54%**：流域 K 在 2030–2050 年 **799.5** + 2060 年管道容量 **7.2**。
罚参数 5×10⁹ 元/单位是我们自己设的惩罚强度，不是价格。扣掉后 **+5.07%**，
且那仍是**下界**——模型并没有守住流域 K 的指标。

**(b) 两臂都是 1% gap，点值不成立。** 按 CLAUDE.md §二.3 的可证边界：
`lo = (LB_t − INC_c)/INC_c = +9.98%`，`hi = (INC_t − LB_c)/LB_c = +12.13%`。符号稳，量级不精确。

**(c) 单个类别的差值只要小于 1% 的目标函数（±135.2 十亿元）就分辨不出来**（§二.4）：
两臂各自的 incumbent 都可以在容差内重排类别，所以**逐类别的差比合计更不可靠，不是更可靠**。
上表最后一行的四项一律不可引用方向或大小。

   并把电解水耗记在供给节点所在流域。这一条同时解掉 §四.2 和 §四.3。

3. **高浓度流股的捕集率**：现在全行业共用 `scenario.capture_rate`。煤气化合成气变换后 CO₂ 纯度 >95%，
   实际可取更高捕集率。
4. **炼化与现代煤化工**：`SECTORS_OUT_OF_SCOPE` 仍在，因为 GB/T 18916.3-2022 与煤化工定额表没拿到。
   补上那两个定额就能开。
