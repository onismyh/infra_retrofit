## 一、问题界定与框架

### 1.1 决策问题

对中国 350 个煤电厂址 hub 与 386 个高耗能工业 hub（输入表 390 个，西藏 4 个读入时剔除，§1.3），在 2030 / 2040 / 2050 / 2060 四个规划年上，
联合决定：每个 hub 的减排路径份额（煤电：不改造 / 退役 / CCS / 掺生物质 / BECCS / 掺氨；工业：不改造 / CCS / 氢路线）、
掺烧档位、湿冷改空冷份额、到期机组的原址重建、CO₂ 候选管网上每条边每期铺几根什么管径的管、每个封存体每年注入多少，
以及生物质 / 绿氨 / 绿氢 / 水在供给节点与 hub 之间的链路流量。目标是**全期贴现系统成本最小**，
约束里有 CO₂ 管网守恒、封存注入与累计容量、部门碳排放上限、资源节点供给上限；有水约束的情景另加水节点生态流量上限与流域取水指标（§8）。

模型是**一个**混合整数线性规划（MILP）：四个年块在同一个 Gurobi 模型里建出来，
跨期约束把它们连起来，一次求解（`opt/solver.py:59-115`）。整数变量只有管道（每边每期每档的整根数与建设 / 新增标志），
hub 级的重建与掺烧档位缺省取连续份额（`hub_decisions_continuous = True`，`opt/scenario.py:318`）。

### 4.1 煤电 hub 份额、到期与存量

$$\sum_k x_{p,k,t}=1\qquad\forall p,t \tag{1}$$
（`opt/model_year.py:93`）；情景关掉的路径 $x_{p,k,t}=0$（`opt/model_year.py:356-361`）。

到期规则（`opt/model_year.py:209-218`）：设计退役年 $ret_p$ 取自 `plants.csv`，

$$t\ge ret_p:\ x_{p,\mathrm{retire},t}\ge 1-\rho_{p,t};\qquad t<ret_p:\ \rho_{p,t}=0 \tag{2}$$

即到期机组要么退役、要么原址重建，未到期不能重建。

捕集岛存量（`opt/model_year.py:190-196`）：
$$R_{p,t}\ge x_{p,\mathrm{ccs},t}+x_{p,\mathrm{beccs},t} \tag{3}$$
CCS 与 BECCS 共用同一座捕集岛，capex 计在 $R$ 的增量上（§5.3）。

### 4.2 掺烧档位的线性化（`opt/constraints.py:107-297`）

每个 hub、每类掺烧各选一组档位份额：
$$\sum_{l=0}^{L_b}\sigma^b_{p,l,t}=1,\qquad \sum_{l=0}^{L_a}\sigma^a_{p,l,t}=1 \tag{4}$$
（`:191-192`）；选了档位 0 的容量不能走掺烧路径：
$$x_{p,\mathrm{bio},t}+x_{p,\mathrm{beccs},t}\le 1-\sigma^b_{p,0,t},\qquad x_{p,\mathrm{amm},t}\le 1-\sigma^a_{p,0,t} \tag{5}$$
（`:197-198`）；数值档位 $\lambda^b_{p,t}=\sum_l l\,\sigma^b_{p,l,t}$、$\lambda^a$ 同（`:201-207`）。

"份额 × 档位"用 McCormick 三条包络（`:28-40`）：对每个 $l\ge1$、每条掺烧路径 $\pi\in\{bio,beccs,amm\}$，
$$z^{\pi}_{p,l,t}\le x_{p,\pi,t},\qquad z^{\pi}_{p,l,t}\le\sigma_{p,l,t},\qquad z^{\pi}_{p,l,t}\ge x_{p,\pi,t}-(1-\sigma_{p,l,t}) \tag{6}$$
生物质与 BECCS 共用改到同一档位的容量（`:230`）：
$$z^{bio}_{p,l,t}+z^{beccs}_{p,l,t}\le\sigma^b_{p,l,t} \tag{7}$$
一条路径的份额恰好分摊到各档位（`:249-250, 267`）：
$$\sum_{l\ge1}z^{bio}_{p,l,t}=x_{p,\mathrm{bio},t},\quad \sum_{l\ge1}z^{beccs}_{p,l,t}=x_{p,\mathrm{beccs},t},\quad \sum_{l\ge1}z^{amm}_{p,l,t}=x_{p,\mathrm{amm},t} \tag{8}$$

独热二元档位下 (6) 精确等于乘积；连续 hub 下 $z$ 是"路径份额里落在该档位的部分"，由 (7)(8) 定分摊
（`:31-34` 与 `:245-248` 的注释）。

燃料用量（`:233, 251, 262, 268`）：
$$\mathcal B_{p,t}=\frac{hr_{p,t}}{10^6}\sum_l\beta^b_l\big(G^{bio}_{p,t}z^{bio}_{p,l,t}+G^{beccs}_{p,t}z^{beccs}_{p,l,t}\big),\qquad
\mathcal N_{p,t}=\frac{G^{amm}_{p,t}\,hr_{p,t}}{LHV_{NH_3}\cdot 10^6}\sum_l\beta^a_l z^{amm}_{p,l,t} \tag{9}$$
单位分别是 PJ（$10^6$ GJ）与 kt（流量缩放 $10^6$，`cr/constants.py:80-82`；`:80` 的注释写作 TJ，按 $10^6$ 应为 PJ），$LHV_{NH_3}=0.0186$ GJ/kg（`opt/scenario.py:29`）。

### 4.3 排放核算：捕集量、残余排放、减排量（`opt/constraints.py:335-433`）

掺烧替代的排放（`:234-235, 263`）：
$$\Delta^{bio}_{p,t}=E^{rt}_{p,t}\sum_l\beta^b_l z^{bio}_{p,l,t},\quad \Delta^{beccs}_{p,t}=E^{rt}_{p,t}\sum_l\beta^b_l z^{beccs}_{p,l,t},\quad \Delta^{amm}_{p,t}=E^{rt}_{p,t}\sum_l\beta^a_l z^{amm}_{p,l,t}$$

**惩罚燃料的排放**。效率损失多烧的煤在同一锅炉燃烧、经同一捕集装置，捕集路径上只有 $(1-\eta)$ 排放、$\eta$ 被捕集
（`opt/plant_matrices.py:81-105`，注释引 `fan2023cofiring` SI eq. S42）：

| 项 | 排放系数 | 被捕集系数 | 代码 |
|---|---|---|---|
| CCS 能耗惩罚，$k\in\{ccs,beccs\}$ | $\pi^{ccs}_{p,k,t}=G^{cost,k}_{p,t}\,\varepsilon^{ccs}_t\,hr_{p,t}\,ef\,(1-\eta)/10^6$ | 同式以 $\eta$ 代 $(1-\eta)$ | `:85-97` |
| 生物质掺烧惩罚，每单位 $\beta z G$ | $\pi^{bio}_{p,t}=\dfrac{0.0373}{0.42}\,hr_{p,t}\,ef/10^6$；BECCS 上乘 $(1-\eta)$ | BECCS 上乘 $\eta$ | `:98-105`；组装在 `opt/constraints.py:240-243` |
| 空冷背压惩罚，$k$ 任意 | $\pi^{air}_{p,k,t}=G^k_{p,t}\cdot\dfrac{0.82}{10^6}\cdot\dfrac{0.020}{0.42}\cdot sw_p\cdot\big(1-\eta\,\mathbb 1[k\in\{ccs,beccs\}]\big)$ | 同式取 $\eta\,\mathbb 1[\cdot]$ | `:240-258` |

$\varepsilon^{ccs}_t$ 为逐年 CCS 能耗惩罚比（§6.2），$sw_p=1-$ 已空冷份额（`:229-234`）。

残余排放（`opt/constraints.py:411-432`）：
$$\begin{aligned}
\tilde E_{p,t}={}&E^{op}_{p,t}x_{p,un,t}+E^{rt}_{p,t}(1-\eta)x_{p,ccs,t}+\big(E^{rt}_{p,t}x_{p,bio,t}-\Delta^{bio}_{p,t}\big)
+\big(E^{rt}_{p,t}(1-\eta)x_{p,beccs,t}-\Delta^{beccs}_{p,t}\big)+\big(E^{rt}_{p,t}x_{p,amm,t}-\Delta^{amm}_{p,t}\big)\\
&+\sum_k\pi^{ccs}_{p,k,t}x_{p,k,t}+\sum_l\beta^b_l\pi^{bio}_{p,t}\big(G^{bio}_{p,t}z^{bio}_{p,l,t}+(1-\eta)G^{beccs}_{p,t}z^{beccs}_{p,l,t}\big)+\sum_k\pi^{air}_{p,k,t}a_{p,k,t}
\end{aligned}\tag{10}$$
减排量 $\Delta_{p,t}=E_{p,t}-\tilde E_{p,t}$（`:433`）；退役份额的减排就是它不再出现在 (10) 里。

物理捕集量（`:391-404`），这是进管网的吨数：
$$c_{p,t}=E^{rt}_{p,t}\,\eta\,(x_{p,ccs,t}+x_{p,beccs,t})+\sum_l\beta^b_l\pi^{bio}_{p,t}\,\eta\,G^{beccs}_{p,t}z^{beccs}_{p,l,t}+\sum_k\pi^{ccs,cap}_{p,k,t}x_{p,k,t}+\sum_k\pi^{air,cap}_{p,k,t}a_{p,k,t} \tag{11}$$

### 4.4 湿冷改空冷与耗水（`opt/constraints.py:305-384`）

$$a_{p,k,t}\le x_{p,k,t}\ \forall k;\qquad A_{p,t}\ge\sum_k a_{p,k,t};\qquad A_{p,t}\ge A_{p,t-1} \tag{12}$$
（`:380-384`、`:321-329`、`:72-74`）；`allow_air_cooling_retrofit=False` 时 $a=A=0$（`:318-319`）。
按路径分列而不用单一空冷比例，是为了保持线性（`:305-310` 注释）。

耗水（Mm³，`:361-378`）：
$$W_{p,t}=\frac{1}{10^6}\sum_k G^k_{p,t}\Big[\omega_{p,k}\,x_{p,k,t}-\big(\omega_{p,k}-\omega^{air}_{p,k}\big)a_{p,k,t}\Big] \tag{13}$$
耗水强度 $\omega$（m³/MWh，`opt/plant_matrices.py:175-208`）：unabated 取 `plants.csv` 的基线耗水强度；ccs / beccs 取表内带捕集的耗水强度
乘情景调整系数（缺省 1）；biomass 取基线 × 1.00；ammonia 取基线 × 1.01；retire 为 0。
基线与带捕集的强度取 `plants.csv` 里按机组查表、再按装机加权的两列（`consumption_intensity_m3_per_mwh`、`consumption_ccs_intensity_m3_per_mwh`，`opt/data_prep.py:62-67`）；缺这两列或设了 `forced_cooling_technology` 时才退回按冷却方式的统一值、带捕集的再 × 1.82（`:68-73`），本输入不走这一支。
空冷矩阵 $\omega^{air}$ 取表内空冷强度，再与湿冷取 $\min$（转换不能反而多耗水，`:208`）。

### 4.5 CO₂ 管网守恒、注入与累计容量

节点净流出（`opt/model_year.py:228-285`）：
$$q_t=B f^+_t-B f^-_t;\qquad q_{n(p),t}=c_{p,t};\qquad q_{n(h),t}=\hat c_{h,t};\qquad q_{n,t}=0\ (n\in N_{pipe});\qquad q_{n(s),t}=-v_{s,t} \tag{14}$$
$\hat c_{h,t}$ 为工业 hub 捕集量（§4.9）。$F_{e,t}=f^+_{e,t}+f^-_{e,t}$。

注入速率（`opt/model_year.py:288-305`）：
$$v_{s,t}\le I_s\,\gamma_t+s^{inj}_{s,t} \tag{15}$$
$\gamma_t=(0.17,0.58,0.80,1.00)$ 为部署进度（`opt/scenario.py:194`，`opt/year_matrices.py:130-133`）；
$I_s=\min\big(\text{可建速率},\ \text{地质上限}\big)\times$ `injectivity_multiplier`，
可建速率 $=(\text{pixel\_count}/100)\times 2$ Mt/yr、上限 200（`opt/data_prep.py:164-180`）。

累计容量（`opt/model_linking.py:198-208`）：
$$\sum_{t'\le t}n_{t'}\,v_{s,t'}\le \mathrm{Cap}_s+s^{sto}_{s,t} \tag{16}$$
$\mathrm{Cap}_s$ 为 `available_capacity_mt`，即 `storage_all_mt` 截到 $\ge0$（`opt/data_prep.py:158`）。

### 4.6 管道：整数管径与在役容量（`opt/model_linking.py:146-197`）

$$y_{e,t}\le \mathbb 1[C^{max}_e>0];\qquad C_{e,t}\le C^{max}_e\,u_{e,t};\qquad u_{e,t}\le\sum_j m_{e,j,t}\le 2\,u_{e,t};\qquad u_{e,t}\le y_{e,t} \tag{17}$$
在役集合 $\mathcal A_t=\{t'\le t:\ t-t'<30\}$（管道寿命 30 年，到寿命的管可原址重铺，`:176-179`）：
$$\sum_{t'\in\mathcal A_t}C_{e,t'}\le C^{max}_e;\qquad F_{e,t}\le C^{base}_e+\sum_{t'\in\mathcal A_t}C_{e,t'}+s^{edge}_{e,t} \tag{18}$$
$C^{max}_e=20\times 2-C^{base}_e$，$C^{base}_e=$ 既有走廊标志 $\times$ `existing_corridor_capacity_mtpa`（缺省 0）$+$ 已加存量（`opt/year_matrices.py:56-61`）。
建成标志与新增标志的联系（`:87-96`）：$y_{e,t}\le\sum_{t'\le t}u_{e,t'}$；建成不可逆 $y_{e,t}\ge y_{e,t-1}$（`:76-84`）。

### 4.7 生物质、绿氨、绿氢、水的链路（`opt/model_resources.py:36-88`）

链路流量在 hub 侧等于用量、在节点侧不超过供给：
$$M^{hub,B}\phi^B_t=\mathcal B_t,\quad M^{node,B}\phi^B_t\le\bar B+s^B_t;\qquad
M^{hub,A}\phi^A_t=\mathcal N_t,\quad M^{node,A}\phi^A_t+\tfrac{1}{0.176}M^{node,H}\psi^H_t\le\bar A_t+s^A_t;\qquad
M^{hub,W}\phi^W_t=W_t,\quad M^{node,W}\phi^W_t\le\bar W_t+s^W_t \tag{19}$$
工业氢从与煤电氨相同的电解节点取，按 $\mathrm{NH_3}$ 当量（$1/0.176$，`cr/constants.py:35`）计入节点上限（`:59-64`）。
水节点上限只在 `water_mode ≠ "no_water"` 时加（`:84-88`）；hub 侧的用水平衡与取水链路两种模式下都有（`:45`，`opt/model_year.py:73`）。

全国上限（`:51-57, 71-82`）：
$$\sum_p\mathcal B_{p,t}\le\frac{16\times10^9}{10^6};\qquad \sum_p\mathcal N_{p,t}\le\bar N_t\cdot10^3;\qquad
0.176\sum_i\Big[M^{node,A}\phi^A_t+\tfrac{1}{0.176}M^{node,H}\psi^H_t\Big]_i\le\bar H_t\cdot10^3 \tag{20}$$
$\bar N_t=(2,12,47,55)$ Mt NH₃（`opt/scenario.py:330`），$\bar H_t=(6.5,69,91,120)$ Mt H₂（`:337`）。

水节点可用量（`opt/water_access.py:22-75`）：$\bar W_{i,t}=\text{径流}_{i,t}\times 0.20\times$ `water_multiplier`，
径流取 `water_availability.csv` 中情景成员（`water_scenario_id`）在年 $t$ 的枯水期列（`water_season="dry"`）或年均列；
0.20 是可提取比例（`cr/constants.py:76`，`richter2012`）；`apply_bias_correction=False` 时把已烘进的乘性偏差因子除回（`:62-69`）。

### 4.8 流域取水指标（`opt/model_resources.py:100-164`）

只在有水约束且 `apply_basin_cap=True` 时加（`opt/water_access.py:146-152`）。煤电取水按取水强度 $\nu$ 计
（与 (13) 同形，`:110-127`；$\nu$ 来自 `bld/water_quota.calibrated_withdrawal_intensities`）：
$$\Omega_{p,t}=\frac{1}{10^6}\sum_k G^k_{p,t}\Big[\nu_{p,k}x_{p,k,t}-(\nu_{p,k}-\nu^{air}_{p,k})a_{p,k,t}\Big]$$
$$U_{b,t}=\sum_{p:\,basin(p)=b}\Omega_{p,t}+\sum_{h:\,basin(h)=b}\Omega^{ind}_{h,t};\qquad U_{b,t}\le\bar Q_{b,t}\cdot\text{water\_multiplier}+s^{basin}_{b,t} \tag{21}$$
（`:140-162`）。hub 按**所在地**的一级流域归属（`plants.basin_code`，`opt/water_access.py:159-166`），不按取水节点。
$\bar Q_{b,t}$ 是 `water_basin_caps.csv` 的 `residual_m3_per_year`，构造在 `bld/water_quota.write_basin_caps`（`:290-345`）：
$$\bar Q_b=\mathrm{cap}_b-\mathrm{reserved}_b\cdot\min\!\Big(1,\tfrac{\mathrm{cap}_b}{\mathrm{actual}_b}\Big)+\mathrm{industry}_b\cdot\min\!\Big(1,\tfrac{\mathrm{cap}_b}{\mathrm{actual}_b}\Big)$$
（`:319-324`）；$\mathrm{cap}_b=\sum_{prov}\mathrm{cap}_{prov}\cdot share_{prov\to b}$（`:157-165`），省级指标为国办发〔2013〕2号附件 1
（`cr/constants_water_quota.py:55`），2030 后取常数（`:149`）；$\mathrm{actual}_b$ 为 2025 年流域实际用水（`:104`）。

### 4.9 工业年块（`opt/model_industry.py:60-160`）

$$\sum_r\xi_{h,r,t}=1;\qquad \xi_{h,r,t}=0\ \text{若路线不可用} \tag{22}$$
（`:73-81`）。CCS 对所有部门开放；氢路线只对长流程钢 / 合成氨 / 甲醇开放（`cr/constants_industry.py:130-137`），且该 hub 有需氢量
（`opt/industry_matrices.py:186-192`）。

产量指数：hub 的排放 $\hat E_h$、产量 $P_h$、现状用水按情景的产量指数逐年缩放（最近规划年取值，`opt/industry_matrices.py:86-93, 119-122`）。

派生表达式（`:82-106`；系数在 `opt/industry_matrices.py`）：

| 量 | 表达式 | 系数 |
|---|---|---|
| 捕集 $\hat c_{h,t}$ | $\hat\kappa_{h,ccs}\,\xi_{h,ccs,t}$ | $\hat\kappa_{h,ccs}=\hat E_{h,t}\,\eta$（`:162`） |
| 减排 $\hat\Delta_{h,t}$ | $\sum_r\hat\delta_{h,r}\xi_{h,r,t}$ | $\hat\delta_{ccs}=\hat\kappa\,(1-\text{蒸汽 CO₂比})$（再生蒸汽由燃煤锅炉产生并放空，`:178-182`）；$\hat\delta_{h2}=\hat E_h\cdot f_{sector}$，$f=(0.95,0.95,0.90)$（`:196`，`cr/constants_industry.py:354-358`） |
| 组残余 | $\sum_{h\in g}(\hat E_{h,t}-\hat\Delta_{h,t})$ | `:94-99` |
| 取水 $\Omega^{ind}_{h,t}$ | $\sum_r\hat w_{h,r}\xi_{h,r,t}/10^6$ | $\hat w_{ccs}=\hat w_{base}+\hat c\cdot10^6\cdot1.65$（`:183`）；$\hat w_{h2}=\hat w_{base}\times$（GB/T 18916 先进值 / 通用值，`:212`, `:77-83`） |

氢平衡与成本地板（`:128-139`）：
$$M^{hub,H}\psi^H_t=\frac{D_h}{10^6}\,\xi_{h,h2,t};\qquad \Theta_{h,t}\ge \mathrm{opex}_{h,h2}\,\xi_{h,h2,t}+\sum_{\ell\in h}\mathrm{cost}_\ell\,\psi^H_{\ell,t} \tag{23}$$
$D_h=k_h\cdot P_{h,t}$ 为满份额需氢量（kg，`opt/industry_matrices.py:211`）；没有任何氢链路时 $D_h>0$ 的 hub $\xi_{h,h2}=0$（`:140-145`）。
氢路线的买氢前年度部分可以为负（文献锚点把省下的化石原料计为收益），所以进目标的是 $\max(0,\cdot)$，用 $\Theta\ge0$ 加下界实现。

能力存量（`:150-160`）：
$$K_{h,r,t}\ge \mathrm{need}_{h,r,t}\,\xi_{h,r,t},\quad r\in\{ccs,h2\};\qquad \mathrm{need}_{ccs}=\hat\kappa_{h,ccs},\ \ \mathrm{need}_{h2}=P_{h,t}/10^6 \tag{24}$$
（`opt/industry_matrices.py:174, 206`）。capex 计在 $K$ 的增量上（§5.3）。

## 五、目标函数与成本口径

### 5.1 结构（`opt/model_costs.py:23-84`，`opt/salvage.py:62-102`，`opt/solver.py:102`）

最小化各规划年成本项之和，除以 `_COST_SCALE` = $10^9$（目标函数以十亿元计，结果乘回 $10^9$ 记 `objective_cny`，`opt/solver.py:135`）：

$$\min\ \sum_t\Big[d_t\,w_t\big(\mathrm{Annual}_t+\mathrm{Penalty}_t\big)+d_t\,\mathrm{OneOff}_t\Big]\;-\;d_{2070}\sum_t\sum_{j}\mathrm{frac}_{j,t}\,\mathrm{Capex}_{j,t} \tag{27}$$

- 年度项（`Annual`）与松弛惩罚乘贴现因子 $d_t$ 与区间年金权重 $w_t$（§1.2；`:57, :59, :70-72`）；
- 一次性 capex（`OneOff`）只乘 $d_t$（`:58, :74-79`）；
- 最后一项是期末残值抵扣（§5.4），只在最后一个规划年的 `cost_exprs["salvage_credit"]` 里出现（其余年份置 0，`opt/salvage.py:82-83, 99`）。

### 5.2 年度项（`opt/model_costs.py:87-186`，`opt/model_industry.py:108-146`）

| 项（`cost_exprs` 键） | 表达式 | 系数来源 |
|---|---|---|
| `baseline_net_cost` | $\sum_{p,k}\mathrm{BN}_{p,k,t}\,x_{p,k,t}$，$\mathrm{BN}=G^k_{p,t}(hr_p\,c^{coal}_p+80-c^{elec}_t)$ | `opt/plant_matrices.py:139-144`；电价 $c^{elec}_t$=(400,440,490,550) CNY/MWh `opt/scenario.py:535`；基线运维 80 CNY/MWh `:125` |
| `carbon_cost` | $c^{CO_2}_t\cdot 10^6\big[\sum_p(E_{p,t}-\Delta_{p,t})+\sum_h\mathrm{Res}_{h,t}\big]$，仅当 $c^{CO_2}_t>0$ 时加入 | `:98-107`；碳价路径 `opt/scenario.py:532` |

### 5.4 期末残值（`opt/salvage.py:55-102`）

$$\mathrm{salvage} = -\,d_{2070}\sum_t\sum_j\max\!\Big(0,\ 1-\frac{2070-t}{L_j}\Big)\,\mathrm{Capex}_{j,t} \tag{28}$$

$2070$ = 末规划年 2060 + 其区间 10 年（`:49-52`）。台账与寿命 $L_j$（`opt/model_costs.py:60-66, 80-83`）：CCS 改造 20、管道 30、掺烧升级 20、空冷 20、重建 30（`opt/scenario.py:277, 291-293, 167`）；工业 CCS 20、工业 H₂ 25（`cr/constants_industry.py:318, 417`）。开关 `end_of_horizon_salvage=True`（`opt/scenario.py:290`）。

### 5.5 松弛惩罚（`opt/model_costs.py:334-350`）

$$\mathrm{Penalty}_t=5\times10^9\,\delta_t+2000\,s^B_t+1000\,s^A_t+1000\,s^W_t+1000\,s^{basin}_t+5\times10^9\,(s^{inj}_t+s^{sto}_t+s^{edge}_t)$$

单位：$\delta$ 与网络松弛为 Mt 或 Mtpa，单价 `slack_penalty_cny_per_unit`=$5\times10^9$（`opt/scenario.py:305`）；资源松弛乘回各自缩放因子 $10^6$（`cr/constants.py:80-82`），即 2000 CNY/GJ、1000 CNY/kg、1000 CNY/m³。流域松弛与节点松弛同价（`:335` 注释）。

### 5.6 成本口径说明

每个减排选项按"改造 capex（一次性，计在存量增量上）+ 固定运维（capex 比例/年）+ 能耗按模型自己的煤价与电价"计价，期末对未折旧 capex 计直线残值。目标函数中**没有**平准化每吨捕集成本：`cr/constants_industry.py:506` 的 `levelised_capture_cost_cny_per_t` 只作报告与交叉核对，不进模型（对应 CLAUDE.md §二.7）。资本回收系数 `capital_recovery_factor`（`:440`）进模型的地方有两处，都不是把平准化 capex 放进目标：(1) 从文献溢价锚点反推氢路线的非氢运行差额时，扣掉锚点里的 capex 年金与固定运维（`:530-567`，§6.5）；(2) 氨价里的合成岛 capex 年金（`bld/supply.py:88`），读入时按情景贴现率重算（`reprice_hb_capex`，`opt/data_prep.py:233-236`）。

### 7.2 两步热启动（`cr/runner.py:327-339`，`cr/run_controls.py:109-129`，`opt/solver.py:104-118`，`opt/solver_start.py:42-101`）

`warm_start="lp_relax"`（`ST_` 系）时：
1. 先把所有整数/二元变量改为连续，解 LP 松弛，时限 `warm_start_time_limit`=1 800 s（`opt/scenario.py:524`），解原样写成 `.sol`（`cr/run_controls.py:109-125`，`opt/solver.py:104-109, 116-118`）；
2. 重新建模解 MILP，读该 `.sol` 按规则取整作为 MIP 起点（`opt/solver.py:110-111`，`opt/solver_start.py:42-101`）：管道每条边每年取覆盖松弛解新增容量的最便宜整根组合（一年不超过 `max_parallel_pipes`=2 根，在役新增容量不超过 20×2 Mtpa；覆盖不了时取容量最大的可行组合），`add_cap` / `build_edge` 随之定；`hub_decisions_continuous=False` 时掺烧档位行取有正值的最高档；其余整数变量向上取整；连续变量不设起点。

接受的终止状态：optimal、suboptimal、solution_limit、以及带可行解的 time_limit（`opt/solver.py:123`）。

### 7.3 可证区间（`scripts/check_run_provenance.py:165-184`，`opt/solver_provenance.py:41`）

每次求解落盘 `objective_cny`（可行解 INC）与 `objective_bound_cny`（Gurobi `ObjBound`，LB）。两个情景 t、c 的相对差报告为区间

$$\mathrm{lo}=\frac{LB_t-INC_c}{INC_c},\qquad \mathrm{hi}=\frac{INC_t-LB_c}{LB_c} \tag{29}$$

分母非正时改报绝对差。结果里没有 `objective_bound_cny` 的旧记录按 $LB=INC-\mathrm{gap}\cdot|INC|$ 反推（`:165-171`）。`ST_` 系 gap 3%，差值只能按 (29) 报告（CLAUDE.md §二.2–3）。CLAUDE.md §二.4 的简并度地板公式**没有**代码实现，本文不作为算法内容。

### 7.4 结果的来源记录（`cr/runner.py:341-357`）

`result.json` 的 `resolved` 记：`registered_as`、`registry_file`、`tree`、`set`、`options`、`env`、解析后的 `scenario` 与 `assumptions`、`warm_start`、`input_files`（路径；文件哈希在 `solver_quality` 的 `digest_*`，`opt/solver_provenance.py:50-73`）、`code`（`commit`、`dirty`）。`check_run_provenance.py --pair` 据此判两次求解可否相减。

### 7.5 命令入口（`cr/cli.py:72-87`）

```
python -m coal_retrofit list                 # 列出能求解的情景
python -m coal_retrofit show <情景>          # 解析后的全部参数，标出与缺省不同的项
python -m coal_retrofit diff <情景A> <情景B>  # 两个情景的参数差
```

`coal_operating_hours_by_year=[3600,3100,2000,1500]`，`warm_start="lp_relax"`）：

| 字段 | `ST_BASE` | `ST_WA_cwatm_126_dry_oq` | `ST_CP_BASE` |
|---|---|---|---|
| 继承 | `ST_COMMON` | `ST_BASE` | `ST_COMMON` |
| `carbon_price_cny_per_t_by_year` | [0, 0, 0, 0] | 同 `ST_BASE` | 缺省 (120, 500, 880, 1260) |
| `sector_target_source` | `times_cn60` | `times_cn60` | `none`（$\mathrm{cap}_{g,t}\equiv1$，式 (25) 只要求各组残余不超过自身 2030 基线） |
| `industry_output_index_source` | 缺省 `""`，实际取 `sector_target_source` → `times_cn60` | 同 `ST_BASE` | `times_cn60`（显式写出，因 `sector_target_source="none"` 时回退值会变成 `none`） |

字段在模型里改变的东西：

- `sector_target_source` 决定 `sector_targets_<source>.csv` 的 `cap_fraction_of_2030` 列（§4.10）；
- `industry_output_index_source` 决定工业产量指数 $P_{h,t}$，从而改变式 (22)–(24) 里的 $\hat E_{h,t}$、氢需求与能力需求（§4.9）；为空时取 `sector_target_source` 的值（`opt/scenario.py:563-566`），所以三个情景的产量指数都是 `times_cn60`；
- `water_mode="grid_supply"` 加水节点上限（式 (19) 的 $M^{node,W}$ 一行，`opt/model_resources.py:84-88`）与流域上限 (21)（`opt/water_access.py:148-149`）；取水链路 $\phi^W$、hub 侧用水平衡 (13)(19) 与 `water_cost` 两种模式下都有（链路 `opt/data_prep.py:269-299`，平衡 `opt/model_resources.py:45`，水费 `opt/model_costs.py:163-167`），所以 `no_water` 情景的目标里也有水费；`water_scenario_id` 与 `water_season="dry"` 选 `water_availability.csv` 的行与 `dry_season_water_m3_per_year` 列（`opt/water_access.py:22-75`）；
- `carbon_price_cny_per_t_by_year` 为零时 `carbon_cost` 项不加入目标函数（§5.2）。

`ST_BASE` 与 `ST_WA_cwatm_126_dry_oq` 只差水约束三个字段；`ST_BASE` 与 `ST_CP_BASE` 在模型里差碳价与部门目标两项，后一对不是单因素对照。`python -m coal_retrofit diff` 比的是两个参数 dataclass 的字段值，不解析回退（`cr/cli.py:184-187`）：前一对列出上面三个水字段；后一对列出三个字段，除碳价与 `sector_target_source` 外还有 `industry_output_index_source`（`""` → `"times_cn60"`），它只把回退值写成显式值，两边实际都用 `times_cn60`。
